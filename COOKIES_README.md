# YouTube Çerez (cookies.txt) Kurulum Kılavuzu

YouTube, sunucu ve bulut ortamlarından (Render, AWS, DigitalOcean vb.) gelen otomatik `yt-dlp` indirmelerini engellemek amacıyla bot doğrulaması (`Sign in to confirm you're not a bot`) talep edebilmektedir. Bu engeli aşmanın en güvenilir yöntemi, geçerli bir YouTube oturum çerezini (`cookies.txt`) projeye tanıtmaktır.

---

## 1. `cookies.txt` Dosyası Nedir ve Hangi Formatta Olmalıdır?

`cookies.txt`, standart **Netscape HTTP Cookie File** formatında bir metin dosyasıdır. Dosya içeriği sekme (`\t`) ile ayrılmış sütunlardan oluşur:

```text
# Netscape HTTP Cookie File
# https://curl.se/docs/http-cookies.html
# This file was generated by Get cookies.txt LOCALLY

.youtube.com	TRUE	/	TRUE	1799999999	VISITOR_INFO1_LIVE	xxxxxxxx
.youtube.com	TRUE	/	TRUE	1799999999	LOGIN_INFO	xxxxxxxx
.youtube.com	TRUE	/	TRUE	1799999999	SID	xxxxxxxx
.youtube.com	TRUE	/	TRUE	1799999999	HSID	xxxxxxxx
.youtube.com	TRUE	/	TRUE	1799999999	SSID	xxxxxxxx
.youtube.com	TRUE	/	TRUE	1799999999	APISID	xxxxxxxx
.youtube.com	TRUE	/	TRUE	1799999999	SAPISID	xxxxxxxx
```

---

## 2. Çerezler Nasıl Alınır? (Adım Adım)

1. **Tarayıcı Eklentisi Yükleyin:**
   - Chrome / Brave / Edge için: **[Get cookies.txt LOCALLY](https://chromewebstore.google.com/detail/get-cookiestxt-locally/cclelndahbckbenkjhflpdbgdldlbecc)** (Açık kaynak ve güvenli)
   - Firefox için: **[cookies.txt](https://addons.mozilla.org/firefox/addon/cookies-txt/)**

2. **YouTube Hesabınıza Giriş Yapın:**
   - Tarayıcınızda [https://www.youtube.com](https://www.youtube.com) adresine gidin ve oturum açın (Öneri: Özel ana hesabınız yerine ikincil bir Google/YouTube hesabı kullanabilirsiniz).

3. **Çerezi Dışa Aktarın:**
   - YouTube sekmesi açıkken eklenti simgesine tıklayın.
   - Sadece YouTube çerezlerini veya tüm çerezleri dışa aktarın (**Export** butonuna tıklayın).
   - İndirilen dosyanın adını `cookies.txt` olarak belirleyin.

---

## 3. Dosyayı Projeye Ekleme

### Seçenek A: Yerel Geliştirme (Local PC)
Dosyayı projenin ana kök dizinine veya `server/` dizinine yerleştirin:
```
media-toolkit/
├── cookies.txt         <-- BURAYA YERLEŞTİRİN (Önerilen)
├── server/
│   ├── cookies.txt     <-- veya BURAYA
│   └── src/
```
Sistem başlatıldığında `cookies.txt` dosyasını otomatik olarak tespit eder ve `yt-dlp` komutlarına `--cookies <yol>` parametresini ekler.

### Seçenek B: Bulut / Render / Docker Ortamı
Bulut ortamlarında dosya yüklemek yerine ortam değişkeni (Environment Variable) kullanabilirsiniz:

1. `cookies.txt` dosyanızın içeriğini Base64 formatına çevirin:
   - PowerShell: `[Convert]::ToBase64String([IO.File]::ReadAllBytes("cookies.txt"))`
   - Linux/Mac: `base64 -w 0 cookies.txt`
2. Render Dashboard -> Environment Variables sekmesinde:
   - Anahtar: `YOUTUBE_COOKIES_BASE64`
   - Değer: Base64 çıktısını yapıştırın.
   *(veya alternatif olarak `YOUTUBE_COOKIES` içine ham metni yapıştırabilirsiniz).*

---

## 4. İstemci Taraflı İndirme (Fallback Alternatifi)

Eğer `cookies.txt` tanımlanmamışsa veya sunucu IP'si tamamen bloklanmışsa:
- Media Toolkit artık **İstemci Taraflı İndirme (Doğrudan Akış URL)** mekanizmasına sahiptir.
- Sunucu videoyu indirip aktarmak yerine doğrudan YouTube CDN akış URL'sini (`yt-dlp -g`) istemcinin tarayıcısına iletir.
- Kullanıcının tarayıcısı indirmeyi kendi ev/mobil IP adresi üzerinden doğrudan tamamlar, böylece sunucu bot engelleri tamamen baypas edilir.

---

## 5. Güvenlik Hatırlatması
> **Önemli:** `cookies.txt` dosyası oturum bilgilerinizi barındırır. Bu dosya `.gitignore` listesine eklenmiştir; kesinlikle GitHub veya halka açık kaynak kod depolarına göndermeyiniz.
